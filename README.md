Физика жұмыстарында SI бірліктері, Word-та өңделетін математикалық формулалар, шешілген есептер және тақырыпқа қатысты сызбалар берілген. Робототехника жұмысында функционалдық құрылым, қоректендіру арналары және блоктардың қызмет кестесі бар. Дереккөздер әр файлдың соңында көрсетілген.

Соңғы тексеру: пән, апта, жұмыс түрі, толық тақырып, студент пен оқытушы деректері, үлгінің сақталуы, мазмұндағы беттер және барлық беттің визуалды көрінісі салыстырылды.
